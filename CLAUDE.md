## Current state

The folder is new. It has no code, build system or tests yet, so there are no build or test commands to run. Update this file when that changes.

## Working conventions

- Put working files (company research, contact lists, outreach drafts, tailored resume and cover letter drafts) in this folder, one file per subject, in Markdown unless another format is needed.
- Start resume bullets with strong resume power verbs.
- Keep facts about people and companies sourced. Say when something is inferred rather than confirmed.
- Never send outreach or messages on the user's behalf. Draft them for review.
- Save durable decisions and findings back to the claude.ai project as well as this folder.

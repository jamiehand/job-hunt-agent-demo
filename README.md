# Job Hunt Agent Demo (Albert's List)

A demo of using Claude as an agent to support a networking-based job search.

## Purpose

Show how Claude can take on the repetitive, research-heavy parts of a job hunt so more time goes to real conversations with people. The demo centers on "Albert's List", the set of people and companies the search is built around.

## What the agent helps with

- **Research:** gathering and organizing information on target companies and roles, such as technical account manager (TAM) and customer-facing technical roles.
- **Networking:** tracking contacts, preparing for informational interviews, and drafting outreach and follow-ups.
- **Application materials:** tailoring resume bullets and cover letters to a specific role.
- **Organization:** keeping notes, status and next steps in one place.

## Project contents

| Location | What it holds |
| --- | --- |
| This Claude project | Shared context, instructions and docs, available across chats |
| `job-hunt-agent-demo/` (local folder) | Working files the agent reads and writes, such as lists, notes and drafts |

## How to use it

1. Add background material (resume, target-company list, contact list) to the project or the local folder.
2. Ask Claude for a specific task, such as "research these three companies" or "draft a follow-up to this contact".
3. Review the output, edit it, and save what is worth keeping back to the project.
